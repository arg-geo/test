1. Introducción al Sistema

Esta herramienta ha sido desarrollada específicamente para cubrir las necesidades académicas de laboratorios de investigación y cartografía en Guatemala. Permite realizar conversiones directas e inversas de coordenadas espaciales entre los sistemas de proyección usados en el país: GTM (Guatemala Transversa Mercator), UTM WGS84 (Zonas 15N y 16N), UTM NAD27 (Zonas 15 y 16 sobre el elipsoide Clarke 1866), y Geográficas WGS84 (tanto en Grados Decimales como en Grados, Minutos y Segundos Sexagesimales).

2. Transformación Individual

Diseñada para verificaciones rápidas en campo o laboratorio. Para procesar un punto:

  • Seleccione el Sistema de Origen y el Sistema de Destino deseado.
  • Si utiliza proyecciones UTM, defina de manera obligatoria la zona correspondiente (15 o 16).
  • Ingrese los valores en las casillas correspondientes. El sistema acepta coordenadas proyectadas de origen con cualquier cantidad de dígitos decimales.
  • Haga clic en Transformar Coordenada. Si el punto es válido, los resultados se desplegarán en tarjetas de alta visibilidad y se abrirá de forma automática un mapa interactivo de control espacial.

3. Procesamiento por Lotes (Masivo)

Permite la carga de archivos planos para la automatización de datos topográficos o geodésicos estructurados.

Restricción Operativa del Servidor: Para resguardar la estabilidad y evitar sobrecargas en las consultas de cobertura geodésica, el sistema cuenta con un límite estricto de hasta 25 puntos por archivo ráfaga. Archivos que excedan esta cantidad serán rechazados de forma inmediata por la interfaz.

4. Estructura Obligatoria del Archivo CSV

El archivo .csv debe estar separado únicamente por **comas ( , )** y contener **únicamente dos columnas de datos**. No se debe incluir ninguna columna de ID o identificador; el sistema asigna automáticamente un correlativo interno ordenado según la posición de la fila.

Columna Nombre del Encabezado Tipo de Dato Descripción y Formato Esperado
1 c1 Numérico / Texto Componente X / Longitud:
• Si el origen es métrico (GTM/UTM): Coordenada Este (Ej: 512450.320).
• Si el origen es Geográfico Decimal: Longitud en grados (Ej: -90.51234500).
• Si el origen es GMS: Cadena de texto sexagesimal (Ej: 90°30'45.2" W o -90 30 45.2).
2 c2 Numérico / Texto Componente Y / Latitud:
• Si el origen es métrico (GTM/UTM): Coordenada Norte (Ej: 1612450.850).
• Si el origen es Geográfico Decimal: Latitud en grados (Ej: 14.61234500).
• Si el origen es GMS: Cadena de texto sexagesimal (Ej: 14°36'50.1" N o 14 36 50.1).

Ejemplo visual del archivo .csv:

c1,c2

489500.000,1585400.750

5. Cobertura Geográfica Nacional y Filtros de Control

Para garantizar la integridad cartográfica de los proyectos y evitar errores de asignación, el backend geodésico implementa un módulo de validación espacial que evalúa en tiempo real si las coordenadas se encuentran en un área delimitada.

  • Latitud Mínima (Límite Sur): 13.5° N
  • Latitud Máxima (Límite Norte): 18° N
  • Longitud Mínima (Límite Este): -88° W
  • Longitud Máxima (Límite Oeste): -92.5° W

Dado que el meridiano 90°W divide los husos cartográficos del país, se aplican límites longitudinales de resguardo para la Zona 15N y la Zona 16N. Los puntos fuera de rango serán marcados como **RECHAZADOS**.
